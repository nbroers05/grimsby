## Voor Claude Code

Dit zijn mockups in een eigen canvas-formaat. Gebruik ze als visuele en structurele referentie, niet als code om over te nemen. Negeer `<x-dc>`, `<helmet>`, `<sc-if>`/`<sc-for>` en het DCLogic-script; bouw het na als gewone HTML/CSS/JS.

- Stijl: volg de Noah Huisstijl zoals in housestyle.css van nbroers05/Dashboard (vensters met titelbalk, eva als hoofdkleur, rood alleen als accent, Shippori Mincho / Zen Kaku Gothic / DotGothic16 / VT323). Hergebruik die CSS in plaats van stijlen opnieuw te schrijven.
- Alle tekst in de mockup is voorbeelddata. Echte inhoud komt uit state.json en /drawings.
- Het wereld-vak is een placeholder voor de latere 3D-wereld: houd daar een lege container met vaste id voor vrij.
- Slaapstand: als de laatste run langer dan 2 uur geleden is.
- Het panel komt later als widget in het dashboard en leest dezelfde data.

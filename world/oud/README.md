# world/oud: the old Berkel world (until 15-11-2026)

Before the island (EILAND.md) his world was the real Berkel en Rodenrijs: 3DBAG buildings + OpenStreetMap,
built by `build_world.py` into `berkel.glb` (Draco), with `poi.json` (OSM places) and `spots/` (cut-outs for
the dashboard panel). Kept here, not used any more. `viewer-berkel.html` is the old viewer; open it from this
folder. `cache/` and `build/` (downloads and intermediates) are local only.
